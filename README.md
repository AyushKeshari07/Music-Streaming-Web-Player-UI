# 🎵 Music Streaming Web Player UI

A clean, modern and responsive **music streaming web player interface** built with front-end technologies. It focuses on a smooth listening experience with an intuitive layout, easy-to-use controls and a visually appealing design.

## 🚀 Features

- 🎧 Music player interface
- 🎵 Song playlist section
- ▶️ Play/Pause and music controls UI
- 📱 Responsive design
- 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

- HTML
- CSS
